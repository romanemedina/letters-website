LETTERS WEBSITE

1. Double-click index.html to open the site in your browser.
2. To add your letters, open script.js in a text editor and replace each [Paste your ... letter here.] placeholder with your writing. Save the file, then refresh your browser.
3. Keep the backticks (`) around each letter. If your writing contains backticks, replace them with ordinary apostrophes.
4. For free hosting, upload the three website files (index.html, style.css, script.js) to a GitHub Pages repository or a static hosting service such as Netlify.

IMPORTANT PRIVACY NOTE: This is a PUBLIC website if you publish it online. Anyone with the link may be able to read the letters. Keep private writing off a public website unless you're comfortable sharing it.

No Squarespace membership is required to run these files.
